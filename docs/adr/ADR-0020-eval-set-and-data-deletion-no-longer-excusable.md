# ADR-0020 — Judge's eval set and data deletion stop being excusable

- **Date:** 2026-08-28
- **Status:** Accepted (requirement) — not yet built as of 2026-09-10
- **Context:** Both gaps (PRD-F14: an eval set, without which M7/K4 are unmeasurable; PRD-F15: forget-me/delete-account, an obligation memory itself created) were waved off under the old four-hour build clock. `apexhuman.md` removed that clock.
- **Decision:** Both become Must-have, not Should-have, features once the time-limit excuse no longer applies.
- **Consequences:** Neither is built yet — tracked as real, current gaps, not resolved by this decision alone.
- **Source:** `docs/prd-intent.md` §3, `apexhuman.md` §8
