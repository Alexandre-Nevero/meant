# ADR-0005 — Calibration and rewards cut from v1

- **Date:** 2026-08-18
- **Status:** Superseded (partially) — see below
- **Context:** Both features risked turning the product into the scored, gamified thing it's explicitly designed against (see `PRODUCT.md` invariants I1/I2, citing engagement-contingent-reward research).
- **Decision:** Cut calibration and reward mechanics from v1 entirely.
- **Consequences:** **Superseded at 0.2:** calibration returns as memory (PRD-F11); reward returns only in the strictly bounded form I2 permits — review only, never during a session. The original cut is why that boundary is so explicit today.
- **Source:** `docs/idea-intent.md` §4
