# ADR-0075 — Premium suspended for the testing phase

- **Date:** 2026-09-22
- **Status:** Accepted
- **Supersedes:** ADR-0015's paywall placement, for the duration of the testing phase only. ADR-0015's *decision that the paywall belongs at the inference-cost boundary* stands unchanged and is what this ADR resumes when the phase ends.
- **Context:** ADR-0015 put the paywall exactly where inference cost sits: free tier is blocking, review and ledger; paid tier is plan, judge, companion's judgment, memory and coach. No code anywhere enforces this today — a repo-wide search for `isPaid`, `paywall`, `tier ===`, `subscription_status`, `quota` returns nothing. The judge and the coach are both about to move from unbuilt/stubbed to real, for-the-first-time model calls (the judge spike's findings, `docs/superpowers/specs/2026-09-21-judge-spike-findings.md`, plus the coach's own upcoming plan). Gating either behind a payment check the moment it becomes real would make it harder to test — every session used to validate the feature would also need a way past the gate, and a synthetic or bypassed gate is worse evidence than no gate.
- **Decision:** **Every feature ADR-0015 marked paid — plan, judge, companion's judgment, memory, coach — is free for the duration of the testing phase.** No quota, no analysis count, no coach-turn limit tied to payment status. This is a testing-phase suspension, not a re-pricing: ADR-0015's placement of the paywall at the inference-cost boundary is not revisited here, and a later ADR must explicitly end the suspension (and say what, if anything, changed about where the line sits) before any paid gate ships.

  This ADR is written **before** any of the code that would have needed a paywall check, per ADR-0063 — no plan downstream of this one may introduce payment-gated behaviour (a `FREE_ANALYSES` counter, a coach-turns paywall, a locked state on the split ring) while this ADR's Status is Accepted.
- **Consequences:**
  - **Cost-control caps are not paywalls and are unaffected.** A daily analysis cap or a coach-turn cap exists to bound API spend and abuse, not to gate free vs. paid — those may still exist, sized for safety, with no reference to payment status in their own rationale.
  - **`docs/superpowers/plans/2026-09-22-verdict-taxonomy.md`'s Task 1 Step 5 and Task 5 are affected**, since they were drafted assuming ADR-0015's paywall was already live. That plan is being revised alongside this ADR to drop the "three analyses free, then paid" decision it was about to record and to cite this ADR instead of a business-line rationale for its remaining caps.
  - **M9 and K6 (PRD §8, `lib/inference-cost.ts`) still apply as engineering discipline.** Free-for-testing does not mean free-of-cost-awareness — `costOf`/`shareOfSubscription` still exist so a runaway cost is visible, it just is not gated behind a purchase yet.
  - **Whoever ends this suspension inherits the actual decision ADR-0015 never fully made**: how many analyses, if any, are free once payment gating resumes. That number is not re-derived here; it was never derived to begin with, and re-deriving it without real usage data would be the same mistake M9/K6 already made once (PRD §8, no mechanism until `lib/inference-cost.ts`).
- **Source:** owner decision 2026-09-22; ADR-0015.
