# ADR-0011 — The session gains a generated plan of 1-5 steps

- **Date:** 2026-08-28
- **Status:** Accepted
- **Context:** Sub-goals help most at initiation (`docs/idea-intent.md` C13/C14), and the judge (ADR-0012) needs something concrete to judge attention against beyond a single free-text sentence.
- **Decision:** After a session starts (never blocking start), generate a 1-5 step plan from the intention. Editable, deletable.
- **Consequences:** Gives the judge and the review something structured to reference. Session start stays instant because the plan arrives after, never gating it.
- **Source:** `docs/prd-intent.md` PRD-F8
