# ADR-0031 — Round 4: companion size/hover pill, popup nav relocation, chip density, review tracking fix

- **Date:** 2026-09-08
- **Status:** Accepted (already shipped)
- **Context:** Direct real-browser feedback surfaced six issues in one batch: a real tracking bug (extension-ID-shaped junk domains crowding out real ones on the review page), the companion read as too small against a supplied reference, its intention was only exposed via a slow unstyled native tooltip, the popup's nav buttons were full-width text at the very bottom, the idle popup read as too many undifferentiated chips, and (noted, not fixed here) `design.md`'s companion section was found to still describe the pre-Orbit-reversal architecture.
- **Decision:**
  - **Tracking bug:** `lib/review-data.ts#getReviewData()`'s `topAttention` query had no extension-ID exclusion filter, unlike `lib/band.ts#toBand()`'s. Exported `EXTENSION_ID_SHAPE` from `lib/band.ts` and imported it into `review-data.ts` rather than redeclaring the regex, so the two call sites can't drift apart again.
  - **Companion size:** `SIZE` in `extension/companion-overlay.js`: 36px → 52px — a real, felt increase while staying well under `PRODUCT.md`'s 80–120px ceiling (that ceiling explicitly rules out treating the companion as a focal element).
  - **Hover pill:** a new Shadow DOM `hoverPill` element, shown on `pointerenter`/hidden on `pointerleave` of the dot (150ms show delay, instant hide), viewport-edge-aware positioning, and — critically — fixed, non-theme-toggled colors (`#F3F1EE`/`#14120F`), because `prefers-color-scheme` reflects the OS, not the arbitrary page background the companion floats over; the same contrast rule already governs the dot itself.
  - **Nav icons:** relocated from full-width bottom buttons into a new top-right header row (`data-popup-header`, no new class). "History" reuses the existing `.m-mark[data-state="ended"]` glyph rather than a new icon; "meant.app" reuses the one other hand-drawn SVG glyph precedent already in the codebase (the landing page's beat-arrow stroke style). Both get real `aria-label`s since their visible text is gone.
  - **Chip density:** the cycle-preset row gets the existing `data-chip-layout="cluster"` grouping treatment (already used for the work-sites/blocklist pair), separating the two numeric presets from the two word options with extra internal gap — explicitly not a disclosure/accordion redesign.
- **Consequences:** The review page now surfaces the domain previously crowded out by junk rows in both known-affected sessions. No new icon system was introduced (would have violated the product's one-icon-system rule). `design.md`'s companion section was confirmed stale during this round but its correction was explicitly deferred as a separate task, not bundled here — see the doc-staleness sweep in `docs/index.md` for where that got fixed.
