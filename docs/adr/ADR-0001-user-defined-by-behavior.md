# ADR-0001 — Define the user by behavior, not job title

- **Date:** 2026-08-18
- **Status:** Accepted
- **Context:** A persona needs a boundary a feature decision can actually test against. "Knowledge worker," "professional," or a job title doesn't say who can install a browser extension, self-direct, and choose to be watched.
- **Decision:** The user is defined by behavior — anyone whose workday is browser plus AI chat, self-employed, browser-native — not by job title, industry, or seniority.
- **Consequences:** Every later feature call ("would this serve them") has a concrete test. Superseded in spirit by ADR-0010, which sharpens "self-employed" specifically against an employed/corporate persona that turned out to have no legal buyer.
